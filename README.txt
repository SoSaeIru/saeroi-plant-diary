새로이 식물일기 PWA

구성
- index.html: 앱 본체
- manifest.webmanifest: 홈 화면 앱 정보
- sw.js: 오프라인 실행용 서비스 워커
- icons/: 홈 화면 아이콘

중요
PWA를 iPad 홈 화면에 앱처럼 추가하려면 이 폴더를 HTTPS 웹주소에서 열어야 합니다.
ZIP 파일을 iPad 파일 앱에서 직접 여는 것만으로는 홈 화면용 웹앱 설치가 완성되지 않습니다.

설치 후 사용
1) Safari에서 배포된 주소 열기
2) 공유 → 홈 화면에 추가
3) '웹 앱으로 열기' 켜기
4) 추가
5) 홈 화면의 '식물일기' 아이콘 실행

데이터
관찰 기록과 사진은 해당 iPad의 웹앱 저장공간(IndexedDB)에 저장됩니다.
Safari/웹사이트 데이터를 지우면 기록도 지워질 수 있으므로 중요한 기록은 추후 백업 기능을 추가하는 것을 권장합니다.
